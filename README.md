# Chambre Lofi

Webapp d'ambiance sonore : une chambre en 3D isométrique où chaque objet lance un son (radio lofi, pluie, bruit blanc, ronron, bruits du dehors).

## Démarrer avec Claude Code

1. Ouvre un terminal dans ce dossier.
2. `git init` puis un premier commit, pour pouvoir revenir en arrière à tout moment.
3. Lance `claude --permission-mode plan`.
4. Colle le prompt de `PROMPT_DEMARRAGE.md`.

## Contenu

- `CLAUDE.md` : contexte du projet, lu automatiquement par Claude Code à chaque session.
- `docs/prototype.html` : le prototype qui marche. Ouvre-le dans un navigateur (connexion internet nécessaire pour charger Three.js et les polices).
- `docs/PROTOTYPE.md` : toutes les valeurs techniques du prototype.
- `docs/PLAN.md` : les phases du projet.
- `docs/captures/` : captures de référence.
